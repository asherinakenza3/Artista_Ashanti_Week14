# Ashanti P. Artista - Week 14 Flutter Activity

Student Information App static UI with two screens:
- Login Screen
- Student Dashboard

## Run
1. Open this folder in VS Code.
2. In the terminal, run `flutter pub get`.
3. Run `flutter devices` to check available devices.
4. Run `flutter run -d chrome` to launch in Chrome.

The login and dashboard are separate static screen previews. The Login button is intentionally disabled because this activity requires static UI only.
